Hacksaw - build instructions (Windows, MSYS2 ucrt64 toolchain)
===============================================================

Prerequisites
-------------
- MSYS2 with the ucrt64 environment: gcc, g++, mingw32-make on PATH
  (C:\msys64\ucrt64\bin)
- CMake 3.16+
- Git

One-time engine dependency setup
--------------------------------
    powershell -File Tools/setup-bgfx.ps1

Clones bgfx/bx/bimg into hksrc/src/Thirdparty (gitignored, ~see .gitignore),
builds the static libs AND shaderc with MinGW GCC. Takes several minutes.
The script handles two MSYS2 quirks for you:
  1. adds C:\msys64\usr\bin to PATH so mingw32-make finds sh.exe
  2. overrides make's MINGW variable so $(MINGW)/bin/... points at
     C:/msys64/ucrt64 (genie's default /bin is Debian cross-layout)

Build the engine
----------------
    cmake -B build -G "MinGW Makefiles"
    cmake --build build -j

Output: Working\hacksaw.exe (CMake RUNTIME_OUTPUT_DIRECTORY)

Shaders
-------
Engine shaders live in hksrc/src/shaders/*.sc (bgfx "shading language").
Compile them to .bin after any .sc change:

    powershell -File Tools/build-shaders.ps1

Output: Working\shaders\*.bin, loaded by the exe relative to its own folder.

Run
---
    Working\hacksaw.exe     (Esc quits)
